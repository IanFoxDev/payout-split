# payout-split

Splits a pool of money between partners by weights. The shares always add up to the
pool, and recalculating a closed period gives the same result.

> Status: in development, nothing released yet.

Why the arithmetic is exact and how the remainder is handled:
[docs/adr/0001-exact-arithmetic-and-the-sum.md](docs/adr/0001-exact-arithmetic-and-the-sum.md).
